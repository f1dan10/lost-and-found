# Matching

An owner who lost something often doesn't know where, so a lost report lists every place it may have been. When a finder files a found item, a reaction [tells the owner of a match](reaction:matching.notifying.NotifyOwnerOfMatch). It runs when `Locating.locate` returns for a found report. It finds each open lost report of the same category that shares one of the found item's places, reading `Locating._getNeighbors`, which gives each such report once however many places they share, and `Reporting._getOpen`, so a lost report that expired unrenewed is not matched, and calls `Notifying.notify` for that report's reporter with the message "An item matching your lost report was found." and the found report as the subject. The frontend builds the page address from the subject, so the message holds no link.

A lost report that shares two places with the found item gives one notice, not two. Two lost reports that match give two notices, one to each reporter, or two to one person who filed both. A lost report that is resolved, withdrawn, expired, in another category, or in other places than the found item's gives none. Because the reaction runs after the endpoint answers, a found item is filed even when a notice or its email fails.

An owner may post after the item was already found. Then nothing new is filed in the found item's place, so the reaction above never runs for it, and the owner would have to notice the card in the list. A second reaction [tells the owner of an earlier find](reaction:matching.notifying.NotifyOwnerOfEarlierFind). It runs when `Locating.locate` returns for a lost report, finds each open found report of the same category that shares one of its places, with the same two queries, and calls `Notifying.notify` for the lost report's reporter with the message "An item that may be yours was already found." and the found report as the subject. Each found report gives one notice. The two reactions never both fire for one pair of reports, because each runs only when the newer of the two is located.
